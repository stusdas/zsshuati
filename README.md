# 趣味刷题小站 V1.3.18

这是可公开部署的源码版本。仓库只包含运行代码和页面资源，不包含 API Key、教师密码、学生账号、学情、错题、真实题库备份或运行日志。

## 环境要求

- Node.js 18 或更高版本
- 不需要安装 npm 依赖

## 本机启动

1. 复制 `server-config.example.json`，改名为 `server-config.local.json`，设置教师登录名和至少 8 位密码。
2. 如需 AI 引导，复制 `智谱Key_只在本机填写.example.txt`，改名为 `智谱Key_只在本机填写.local.txt`，只填写智谱 API Key。
3. 双击 `启动趣味刷题小站.bat`，或执行：

```powershell
npm start
```

4. 打开：`http://127.0.0.1:8792/趣味刷题小站第一版.html`

首次保存时，服务器会自动创建 `题库数据备份/`、`错题本数据/` 和 `运行日志/`。这些目录被 Git 忽略，真实数据不会被提交。

## AI Key 的安全方式

Key 只存在运行服务器上，不进入网页，也不提交到 GitHub。服务器按以下顺序读取：

1. 环境变量 `ZHIPU_API_KEY`；
2. `ai-guide-secrets.local.json` 中的 `zhipuApiKey`；
3. `智谱Key_只在本机填写.local.txt`。

前端只请求本站 `/api/ai`，由 Node 服务端代为访问智谱接口，因此学生浏览器看不到 Key。

## 数据说明

浏览器 `localStorage` 仅作为缓存。跨设备共享的数据由服务器接口保存到以下本机目录：

- `题库数据备份/当前题库与学习记录.json`
- `错题本数据/`
- `运行日志/`

如果需要迁移现有题库，请在服务器停止时，把已有的 `当前题库与学习记录.json` 放入 `题库数据备份/`。不要把含学生数据的文件推送到公开仓库。

## 公网访问

推荐把 Cloudflare Named Tunnel 指向 `http://127.0.0.1:8792`。公网只需要暴露固定 HTTPS 域名，不需要开放路由器端口。教师账号、API Key 和真实数据仍只保存在运行服务器本机。

## 安全提醒

- 上线前务必修改教师密码。
- 不要删除 `.gitignore` 中对 `.local` 文件和数据目录的规则。
- 当前访客入口可直接使用；正式大规模开放前应增加 AI 接口频率限制。
